# FullAuto100

스토브 플레이크샵의 미션 보상과 오늘 남은 100 플레이크 캡슐 뽑기를 순서대로 처리하는 크롬 확장 프로그램입니다. Windows 설치 도우미가 포함됩니다.

## 설치

1. [최신 릴리즈](https://github.com/LibraLightLuda/FullAuto100/releases/latest)에서 `FullAuto100-Setup-v버전.exe`를 받습니다.
2. EXE에서 설치 폴더를 고르고 **선택한 폴더에 설치**를 누릅니다.
3. **관리 주소 복사**를 누르고 크롬 주소창에 붙여 넣습니다.
4. **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
5. **설치 경로 복사**를 누르고, 폴더 선택창에서 **Alt+D → Ctrl+V → Enter → 폴더 선택**을 누릅니다.

처음 등록은 사용자가 크롬에서 완료합니다. 기존 확장을 업데이트할 때는 같은 폴더에 설치하고 크롬 목록의 **새로고침(↻)**을 누릅니다.

## 실행과 업데이트

- 스토브에 로그인한 크롬에서 확장 아이콘의 **자동 처리 시작**을 누릅니다.
- 미션, 게시글, 설문, 클릭 보상 후 오늘 남은 100 플레이크 뽑기를 30회 한도까지 처리합니다.
- 준비된 보상은 바로 수령하고, 캡슐 결과창과 수령 가능한 누적 보상을 확인합니다.
- 스토브 포인트 경품 1회 응모는 기본 해제입니다. 선택한 경우 화면에서 확인한 플레이크 비용을 사용합니다.
- 진행률, 중지, 완료 창과 최근 5회 실행 로그를 제공합니다.
- 크롬이 열려 있으면 하루 한 번 GitHub 릴리즈를 확인합니다. 확장 아이콘을 열면 새 버전을 표시하며, **업데이트 확인**으로 즉시 확인할 수 있습니다.
- **최신 설치 파일 받기**로 EXE를 받은 뒤 실행합니다. 설치 도우미도 최신 버전을 확인하며, 새 EXE를 받아 SHA-256을 검증한 뒤 열 수 있습니다.
- 설치 도우미는 최근 설치 경로를 기억합니다. 해당 폴더에 파일을 설치하고 크롬 확장을 새로고침합니다. 실행 중에는 업데이트를 진행하지 않습니다.

## 로컬 빌드와 검사

Windows, PowerShell 7, Node.js 22 이상과 Windows에 포함된 .NET Framework C# 컴파일러를 사용합니다.

```powershell
npm ci
npm run build
npm test
npx playwright install chromium
npm run test:browser
pwsh -File tools/release.ps1
pwsh -File tools/test-installer.ps1
```

`dist/`에 설치 EXE, 확장 ZIP과 SHA256SUMS.txt를 생성합니다. 공개 릴리즈는 변경을 커밋한 뒤 `tools/release.ps1 -Publish`로 배포합니다. 태그가 이미 있으면 덮어쓰지 않습니다.

## 코드와 데이터

엔진 원본은 `outputs/stove-100.js`입니다. `npm run build`로 확장 폴더의 `engine.js`에 복사합니다. 실행 코드, Windows 설치 소스, 테스트와 릴리즈 빌드만 이 저장소에서 관리합니다.

실행 기록은 PC의 크롬 저장소 및 다운로드 폴더 아래 `FullAuto100-logs/recent-runs.json`에 저장됩니다. 업데이트 확인은 GitHub의 공개 릴리즈 API에 접속하며 스토브 실행 기록을 보내지 않습니다. 설치 경로는 현재 사용자의 `%LOCALAPPDATA%\FullAuto100\install-path.txt`에 저장합니다.

사이트 변경으로 처리가 달라질 수 있습니다. 격리 테스트 결과는 실제 계정의 보상 수령 결과와 구분합니다. 설치 EXE는 현재 디지털 서명 없이 배포됩니다. 이 프로젝트는 스토브 공식 제품이 아닙니다.
