# FullAuto100 v5.7.0 백그라운드 실행

이번 버전의 무인 실행은 크롬 확장 기능에서 시작합니다. F12 스니펫만 바꾸는 것으로는 크롬의 백그라운드 실행과 새 탭 제어 권한을 얻을 수 없습니다.

## 한 번만 설치

1. Windows에서 **FullAuto100-Setup-v5.7.0.exe**를 엽니다. **폴더 찾기** 또는 경로 입력칸을 이용해 `manifest.json`이 들어갈 폴더를 선택합니다. 기본 경로는 `%LOCALAPPDATA%\FullAuto100\extension`입니다. 새 경로는 자동으로 만들며, 기존 폴더는 비어 있거나 FullAuto100 설치 파일만 있어야 합니다.
2. **선택한 폴더에 설치**를 누릅니다. 파일 준비가 끝나면 **설치 폴더 열기**로 `manifest.json`이 들어 있는지 확인할 수 있습니다.
3. **관리 주소 복사**를 누르고, 사용할 크롬 프로필의 주소창에 붙여 넣어 `chrome://extensions/`를 엽니다. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 설치 창에서 **설치 경로 복사**를 누릅니다. 크롬의 폴더 선택창으로 돌아가 **Alt+D → Ctrl+V → Enter**를 누르고 **폴더 선택**을 누릅니다.
5. 목록에서 **FullAuto100 백그라운드 실행 5.7.0**를 확인합니다. 크롬 퍼즐 아이콘에서 고정한 뒤 설치 창을 닫아도 됩니다.

ZIP을 사용한다면 먼저 압축을 풀고, `chrome://extensions/`에서 `manifest.json`이 들어 있는 폴더를 직접 선택합니다.

**업데이트**할 때는 자동 처리를 중지한 뒤 EXE에서 크롬에 등록한 것과 **같은 폴더**를 선택합니다. 파일 설치 후 크롬 목록에 있는 기존 FullAuto100 항목의 **새로고침(↻)**을 누릅니다. 폴더를 바꿨거나 첫 설치라면 위 3~5번으로 등록합니다.

## 매일 실행

1. 스토브에 로그인된 크롬에서 시작합니다. 플레이크샵을 미리 열어 둘 필요가 없습니다.
2. 이전 스니펫이 실행 중이면 먼저 중지합니다. **F12 개발자도구를 닫습니다.**
3. 어느 탭에서든 FullAuto100 확장 아이콘 → **자동 처리 시작**을 누릅니다. 열린 플레이크샵 탭이 있으면 재사용하고, 없으면 `https://reward.onstove.com/ko` 미션 화면을 새 백그라운드 탭으로 엽니다.
4. 이후 다른 프로그램을 사용하거나 크롬 창을 최소화해도 됩니다. 이 스토브 탭은 열어 둡니다.
5. 확장 아이콘을 열면 미션과 캡슐 뽑기의 진행 막대와 **완료한 수 / 이번 처리 대상 수**가 표시됩니다. 실행이 끝나면 완료·일부 미완료·중지·오류 상태를 표시합니다.
6. 미션과 뽑기, 수령 가능한 누적 보상 확인까지 끝나면 별도 **완료** 창이 열립니다. 모두 이미 완료된 날에도 완료 창을 표시합니다.

페이지 로딩이 끝난 뒤 처리하며, 로그인 페이지로 이동하거나 준비 탭이 닫히거나 로딩 시간이 초과되면 이유를 기록하고 중지합니다. 준비 중에도 중지 버튼을 사용할 수 있습니다.

실행 중 개발자도구를 다시 열거나 크롬의 디버깅 종료 안내를 누르면 연결이 끊길 수 있습니다. 연결 해제, 새로고침, 페이지 이탈 시 자동 재실행하지 않고 오류로 남깁니다. PC 절전·종료, 크롬 종료, 인터넷 단절까지 계속 실행할 수는 없습니다.

## 처리 순서

- 같은 탭에서 미션 화면을 먼저 처리합니다. 이미 **받기**가 활성화된 항목은 미션하기·설문 선택 없이 바로 수령합니다. 미니게임 플레이/참여, 앱 로그인 등 별도 활동은 실행하지 않습니다.
- 미션하기 → 응답 확인 → 해당 미션이 연 새 창·새 탭 닫기 → 받기 → 수령 확인 → 다음 미션 순서입니다.
- 인기 게시글, 설문, 아래쪽 **클릭 시 N 플레이크** 배너를 모두 순서대로 확인합니다. 게시글 한 개만 표시되는 화면과 옆으로 넘겨야 하는 배너도 처리합니다. 이미 완료된 항목과 같은 링크의 중복 카드는 건너뜁니다.
- 설문은 기존 선택을 유지하고, 수령 버튼이 활성화될 만큼 필요한 선택만 추가합니다.
- 직접 클릭으로 지급되는 보상은 완료 표시나 수령 알림을 확인합니다. 별도 받기 버튼이 생기면 그것도 누릅니다. 단순 HTTP 성공만으로 수령 완료를 기록하지 않습니다.
- 미션 처리가 끝나면 캡슐 뽑기로 이동합니다. 오늘 30회라면 뽑기를 생략하고, 남은 횟수만 100 플레이크로 뽑습니다.
- 캡슐 결과창이 남아 있으면 닫고, 누적 횟수에 따라 활성화된 **플레이크 받기**를 순서대로 수령합니다.
- 미션 응답이 시간 초과되면 상태 조회와 응답 확인을 두 번 더 시도합니다. 재조회가 확인되고 기존 방문 요청이 감지되지 않은 게시글·배너 링크는 다시 열 수 있습니다. 세 번의 확인에도 완료를 확인하지 못하면 그 항목을 미완료로 기록하고 나머지를 계속 처리합니다.
- 이미 받았거나 자동 처리 대상에서 제외된 항목은 이번 처리 대상 수에 포함하지 않습니다. 수령을 확인하지 못한 항목은 막대의 남은 수에 포함합니다.

## 스토브 포인트 1회 응모 옵션

확장 팝업의 **스토브 포인트 경품에 1회 응모**는 기본 해제이며 저장하지 않습니다. 체크하면 미완료 경품 미션에서 표시된 스토브 포인트 경품 중 금액이 가장 큰 항목에 1회 응모합니다. 이미 받기가 가능하거나 완료했다면 응모 비용을 추가로 사용하지 않습니다. 화면에 표시된 플레이크 비용과 수량 1회를 확인하고, 응모 응답과 선택한 경품의 내 응모 횟수 증가를 확인한 뒤 미션으로 돌아가 보상을 수령합니다. 대상·수량·잔액·응답이 불확실하면 재응모하지 않고 이유를 남깁니다.

## 권한과 데이터

`debugger`는 실행 탭을 활성 상태로 처리하고 각 클릭을 브라우저 입력 문맥에서 실행하는 데 사용합니다. 크롬에 디버깅 안내가 표시되는 것은 정상입니다. `webNavigation`은 실행한 탭에서 생성한 새 창·새 탭의 출처를 확인하는 데 사용합니다. `storage`는 마지막 실행 결과를 이 PC에 저장합니다.

실행 대상은 `https://reward.onstove.com/ko` 아래로 제한합니다. 기존 다른 탭을 일괄 닫거나 전역 팝업 차단 설정을 바꾸지 않습니다. 로그인 정보·쿠키를 추출하지 않으며 별도 서버에 로그를 전송하지 않습니다. 자동 폐기 방지와 활성 상태 처리는 종료 시 복원합니다.

## 최근 실행 로그

확장 팝업의 **로그 폴더 열기**를 누르면 크롬 다운로드 위치의 `FullAuto100-logs` 폴더를 열고 `recent-runs.json`을 표시합니다. 파일의 `runs` 배열은 최신 실행부터 최대 다섯 번의 실행을 담습니다. 시작 준비, 진행 단계, 미션별 재확인·응답·실패와 종료 상태를 확인할 수 있습니다.

기록은 실행 중에도 크롬에 저장합니다. 작업이 종료되거나 폴더를 열 때 파일을 갱신하며, 크롬이 실행 도중 종료되면 다음 시작 때 마지막 저장 상태를 **실행 끊김**으로 남깁니다. 다운로드 권한은 이 파일을 저장하고 폴더에서 표시하는 데 사용합니다.

## 검증 범위

실제 Chrome for Testing의 기본 백그라운드 제한·팝업 차단을 유지한 격리 화면에서 최소화, 다른 탭 선택, 애니메이션 기반 뽑기, 이름 있는 새 창, noopener 새 탭, 응답 후 수령, 이미 완료된 항목, 서버 오류, 중지를 검증했습니다. 실제 스토브 계정의 새로운 뽑기·보상 수령은 이 검증에 포함되지 않습니다.

## 새 버전 확인과 업데이트

확장 팝업의 업데이트 확인으로 최신 GitHub 릴리즈를 조회합니다. 새 버전이 있으면 최신 설치 파일 받기를 누르세요. 하루 한 번 자동 확인도 수행합니다.

받은 EXE를 실행해 기존 크롬에 등록된 것과 같은 폴더에 설치한 다음, 크롬 확장 관리에서 새로고침을 누릅니다. 설치 도우미는 기존 설치 경로를 기억하고, 새 EXE를 받을 때 GitHub 릴리즈에 기록된 SHA-256과 파일을 비교합니다. 최초 등록은 크롬에서 폴더를 선택해 마칩니다.
